# Versions épinglées pour le dessin, pas pour les octets : c'est le rendu de
# Pillow qui doit rester stable d'une version à l'autre, puisque le contrôle
# compare les pixels. Laissée flottante, une montée amont qui changerait un
# antialiasing ou un arrondi ferait échouer le contrôle sur du travail que
# personne n'a touché.
#
# L'identité des octets, elle, n'est pas atteignable par épinglage : la wheel
# Windows charge zlib-ng là où la wheel Linux charge zlib, à Pillow identique.
#
# Monter une version est donc un lot en soi : régénérer, relire quelques
# planches de contrôle, et la montée emporte le diff des ressources avec elle.
pillow==12.2.0
numpy==2.5.2
scipy==1.18.1
